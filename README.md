**The Copper Ladle** — a diner-rescue cooking game. Rosa has 12 days to repay the bank loan or lose her diner. Cook by *clicking*: active, forgiving click-cooking with a wide PERFECT zone and no burning, ever. 26 recipes built layer by layer from 29 hand-drawn ingredients, 6 customer types plus Marco the loyalty-heart regular, combos and FEVER mode, dish of the day, order variations, a drinks machine, mise en place, phone takeaway orders, a stage ladder with 1–3 stars per day, a night shop with upgrades and visible decor, helper staff, story scenes, achievements, a recipe book, Relaxed/Normal difficulty, a guided tutorial, and an unlockable Endless mode. All art is drawn in code; all sound is synthesized WebAudio. It plays fully offline in a desktop browser.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts   # build the hand-in (dossier + files)
cd game && python3 -m http.server 8080               # then open http://localhost:8080 to play
```
